# Travel readiness scope

Read `docs/features/travel-readiness/FEATURE.md`, `docs/domain/readiness.md`, and `docs/rules/readiness-and-safety.md`.

This package owns safety advisories, passport-aware entry, health, weather, culture, practical preparation, and grounded planning constraints. It does not own places, events, restaurants, inventory, routes, prices, or final itinerary selection.

Preserve bounded retrieval, official-source policy for sensitive topics, field citations, immutable preflight/detail assembly, request fingerprints, and fail-closed critical coverage. A stale or insufficient preflight cannot authorize downstream discovery. Provider failures remain typed outcomes.

Run focused readiness unit, provider, weather, API-contract, and deterministic EDD tests. Live Tavily/model evaluation requires explicit approval and cost disclosure.
