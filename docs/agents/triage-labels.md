# Triage labels

The engineering skills use these canonical roles and label strings:

- `needs-triage`: maintainer evaluation is needed
- `needs-info`: waiting for more information from the reporter
- `ready-for-agent`: fully specified and ready for an agent
- `ready-for-human`: requires human implementation
- `wontfix`: will not be actioned

When a skill mentions a triage role, use the matching label string above.
